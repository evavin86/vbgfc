Python Mini-Course

Урок 1: Основы синтаксиса и переменные

Python — это интерпретируемый язык. Код выполняется сверху вниз. Переменные создаются присваиванием:

name = "Алиса"
age = 25
pi = 3.14

Типы данных определяются автоматически. Для вывода используем print():

print("Привет,", name)
print("Тебе", age, "лет")

Напиши код, который выводит твоё имя и возраст.

Урок 2: Условия и циклы

Условные конструкции в Python используют отступы вместо скобок:

x = 10
if x > 5:
    print("x больше 5")
else:
    print("x меньше или равно 5")

Цикл for перебирает элементы:

numbers = [1, 2, 3, 4, 5]
for n in numbers:
    if n % 2 == 0:
        print(n, "— чётное")

Практика

Выведи все числа от 1 до 10, которые делятся на 3.

Урок 3: Функции и работа со строками

Функции объявляются через def. Они могут принимать аргументы и возвращать значения:

def greet(name):
    return f"Привет, {name}!"

message = greet("Мир")
print(message)

Со строками удобно работать через методы:

text = "python"
print(text.upper())      # PYTHON
print(text.capitalize()) # Python
